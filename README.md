📌 Project Description – SmartGrocery: Online Grocery E-Commerce System

SmartGrocery is an online grocery e-commerce platform developed as part of the Object-Oriented Analysis and Design (OOAD) course project. The system is designed to modernize the grocery shopping experience by providing a seamless, user-friendly platform for customers, administrators, and delivery drivers.

🔹 Key Features

For Customers:

User registration and login

Browse and search products

Add/remove products from cart

Place orders (with minimum order limit)

Choose payment methods (Online / Cash on Delivery)

View order history and receive driver details after order

For Admins:

Secure login

Add, update, and delete products

Monitor inventory with low-stock alerts

View/manage all orders

Assign delivery drivers

Generate best-selling product reports

For Drivers:

Secure login

View assigned orders and delivery details

Check payment status (COD or Online)

Mark payment received (for COD orders)

Update delivery status

🔹 Technology Stack

Frontend: ASP.NET MVC

Backend: C# with ADO.NET & Dapper ORM

Database: Microsoft SQL Server

Payment Integration: Online gateways (e.g., EasyPaisa) & COD

Security: User authentication, input validation, session management

🔹 Objectives

Provide a convenient shopping experience for users with flexible payment and order tracking.

Help admins automate store management, inventory monitoring, and order assignments.

Enable drivers to efficiently manage deliveries with real-time updates.

Ensure scalability and future expansion to multi-store support, loyalty systems, and mobile platforms.

⚡ This repository demonstrates the application of OOAD principles (encapsulation, abstraction, inheritance, modularity) in building a structured, scalable, and real-world system.
